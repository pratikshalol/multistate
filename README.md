# MultiState Banking Website

A responsive banking website built using **CodeIgniter 4, PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

## Features

- Banking services and account information
- Deposits and loan sections
- Responsive and modern UI
- Admin panel for managing website content
- MySQL database with migrations and seeders

## Tech Stack

- PHP
- CodeIgniter 4
- MySQL
- HTML / CSS / JavaScript
- Bootstrap
