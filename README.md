# MultiState Banking Website
A modern and responsive banking website built using **CodeIgniter 4, PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

## Features
- Banking services and account information
- Deposits and loan sections
- Responsive and minimal UI
- Scroll reveal animations
- Admin panel for managing website content
- MySQL database with migrations and seeders

## Tech Stack
- PHP
- CodeIgniter 4
- MySQL
- HTML / CSS / JavaScript
- Bootstrap
